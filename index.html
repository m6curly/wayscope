Choose a basemap

Switch the map background at any time. Historical object layers stay in place. The active provider's tile attribution appears in the map corner.

These public basemaps are configured without API keys. Providers have separate attribution, commercial-use and fair-use rules, and availability can change. No public tile service is unlimited or guaranteed.

Quick guide

  1. Load history for a Way, Node or Relation by ID, or upload its OSM XML. Changesets show the objects in that edit batch.
  2. Turn layers on or off to compare historical shapes.
  3. Choose a version to inspect its date and editor.
  4. Export the selected version or the complete history.

Where can I get the XML?

Use the object search on the map to load Way, Node or Relation history directly. You can also upload that object's OSM XML history. A changeset is an edit batch rather than a versioned object, so its view shows the objects included in the changeset download.

OpenStreetMap ↗

Historical geometry is resolved through the OpenStreetMap API. Place-name search uses Photon based on OpenStreetMap data. Search is on demand, not autocomplete. Internet access is required; public tile and geocoding services can be rate-limited or unavailable.
